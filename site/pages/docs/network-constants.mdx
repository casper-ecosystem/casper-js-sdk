# Network Constants

Mainnet parameters sourced from the Casper 2.1 chainspec. These values are enforced at the protocol level.

## Chain Identity

| Parameter | Value |
|---|---|
| Network name | `casper` |
| Testnet name | `casper-test` |
| Protocol version | `2.1.2` |

## Token & Motes

| Parameter | Value |
|---|---|
| 1 CSPR | `1_000_000_000` motes |
| Minimum transfer | `2_500_000_000` motes (2.5 CSPR) on mainnet |
| Minimum delegation | `500_000_000_000` motes (500 CSPR) on mainnet |
| Maximum delegation | `1_000_000_000_000_000_000` motes |

```ts
// Convert CSPR to motes
const motes = BigInt(cspr) * 1_000_000_000n;

// Minimum transfer (2.5 CSPR)
const MIN_TRANSFER_MOTES = '2500000000';

// Minimum delegation (500 CSPR)
const MIN_DELEGATION_MOTES = '500000000000';
```

## Transactions

| Parameter | Value |
|---|---|
| Maximum TTL | 2 hours |
| Default TTL | 30 minutes (1,800,000 ms) |
| Max approvals per block | 2,600 |
| Max block size | ~2.5 MB |
| Block gas limit | 812,500,000,000 |

:::note
Transaction TTL is measured in milliseconds in the SDK. The max allowed TTL is 2 hours (`7_200_000` ms). Transactions with a higher TTL will be rejected by the node.
:::

## Gas & Fees

| Parameter | Value |
|---|---|
| Gas per stored byte | 1,117,587 |
| Native transfer cost | 100,000,000 motes (0.1 CSPR) |
| Fee handling | Burned (not redistributed) |
| Unused gas refund | 75% returned to sender |

## Consensus & Eras

| Parameter | Value |
|---|---|
| Consensus protocol | Zug |
| Era duration | ~120 minutes (~440 blocks) |
| Minimum era height | 100 blocks |
| Minimum block time | 8,000 ms (target; actual production may vary) |
| Validator slots | 100 active validators |
| Max delegators per validator | 1,200 |

## Staking Delays

| Parameter | Value | In Time |
|---|---|---|
| Auction delay | 1 era | ~2 hours (validator set for era N+2 is selected at era N) |
| Unbonding delay | 7 eras | ~14 hours (funds locked, slashing still possible during this window) |

:::warning
When you call `NativeUndelegateBuilder` and submit the transaction, staked funds are **not** immediately returned. They enter an unbonding queue and are released after ~7 eras (~14 hours).
:::

## Ports

| Service | Port | Description |
|---|---|---|
| RPC | `7777` | JSON-RPC 2.0 API (`RpcClient`) |
| Speculative | `7778` | Dry-run execution (`SpeculativeClient`) |
| SSE | `9999` | Real-time event stream (`SseClient`) |
| REST | `8888` | Lightweight status/chainspec queries |

## Public Nodes

You can use these public endpoints during development. For production, run your own node or use a dedicated RPC provider.

| Network | URL |
|---|---|
| Mainnet | `http://65.21.235.219:7777/rpc` |
| Testnet | `http://136.243.187.84:7777/rpc` |

:::warning
Public nodes may be rate-limited, restarted, or removed at any time. Do not rely on them in production applications.
:::
