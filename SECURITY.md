# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in the Casper JS SDK, please report it privately by email to [security@make.software](mailto:security@make.software).

Please do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

To help us triage and fix the issue quickly, please include as much of the following as you can:

- The type of issue and its potential impact
- The `casper-js-sdk` version, the runtime (Node.js version, or browser and bundler) and, if relevant, the Casper network involved
- Step-by-step instructions to reproduce the issue (a proof of concept is very helpful)
- Any relevant configuration or environment details

Issues in key generation, key import/export, signing, or transaction serialization are the highest priority — a defect there can cost users funds — so please say up front if your report touches one of them.

We will acknowledge your report and keep you informed of the progress towards a fix. We kindly ask you to keep the details of your report confidential until a fix has been released.

## Supported Versions

Only the latest released version of `casper-js-sdk` receives security updates.
