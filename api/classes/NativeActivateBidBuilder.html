    Class NativeActivateBidBuilder

    Builder for creating Native Activate Bid transactions. Used by validators to activate their bid after it has been deactivated.

    Example

    const transaction = new NativeActivateBidBuilder()
      .from(validatorPublicKey)
      .validator(validatorPublicKey)
      .chainName('casper')
      .payment(2_500_000_000)
      .build();
